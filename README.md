# تنبيه توفر ألوان البف على تيليجرام

برنامج صغير يشتغل على سيرفرات GitHub مجاناً، كل 5 دقائق يفحص مخزون البف في بوتيكات.
إذا لون أو حجم كان **غير متوفر** وصار **متوفر**، يرسل لك رسالة تيليجرام فيها الاسم والحجم والسعر والرابط.
يشتغل حتى لو جهازك طافي، وما يلمس أي ملف من برنامجك الحالي.

---

## الطريقة الأسهل: تطبيق ntfy (إشعار على الجوال)

1. نزّل تطبيق **ntfy** من App Store أو Google Play (مجاني).
2. افتحه واضغط **+** واكتب اسم قناة سري (مثل `puff-` وبعدها أرقام وحروف عشوائية)، واضغط Subscribe.
3. في GitHub أضف Secret اسمه `NTFY_TOPIC` وقيمته نفس اسم القناة.
4. شغّل التجربة (الخطوة 3 تحت). لو ضبطت تيليجرام بعد، يرسل على الاثنين.

## الخطوة 1: سوّ بوت تيليجرام (دقيقتين)

1. افتح تيليجرام وابحث عن **@BotFather** (عليه علامة توثيق زرقاء).
2. اضغط **Start** واكتب: `/newbot`
3. يطلب اسم للبوت، اكتب أي اسم مثل: `PUFF تنبيه`
4. يطلب يوزر ينتهي بكلمة bot، مثل: `puff_alert_123_bot`
5. يعطيك **التوكن**، شكله كذا: `7123456789:AAH...` . انسخه واحفظه، لا تعطيه أحد.
6. افتح البوت الجديد (الرابط اللي أعطاك إياه BotFather) واضغط **Start**. هذي مهمة، بدونها ما يقدر البوت يراسلك.

## الخطوة 2: حط التوكن في المستودع (Secret)

1. افتح صفحة المستودع على GitHub.
2. اضغط **Settings** ثم من القائمة اليسار **Secrets and variables** ثم **Actions**.
3. اضغط **New repository secret**.
4. في Name اكتب بالضبط: `TELEGRAM_TOKEN`
5. في Secret الصق التوكن، واضغط **Add secret**.

رقم المحادثة: أول تجربة (الخطوة 3) البوت بيرسل لك رسالة فيها **رقم محادثتك**.
انسخه وأضف Secret ثاني بنفس الطريقة، اسمه بالضبط: `TELEGRAM_CHAT_ID`
(ما نحفظه داخل المستودع لأن المستودع عام.)

## الخطوة 3: التجربة الأولى

1. في المستودع اضغط تبويب **Actions**.
2. اختر **PUFF restock alert** من اليسار.
3. اضغط **Run workflow**، وعلّم على خيار **Test only**، واضغط **Run workflow** الأخضر.
4. انتظر دقيقة:
   - بتوصلك رسالة فيها رقم محادثتك، حطه في Secret اسمه `TELEGRAM_CHAT_ID` (الخطوة 2).
   - بعدها شغّل التجربة مرة ثانية، إذا وصلتك رسالة «✅ تجربة ناجحة» كل شي تمام.
   - إذا طلعت علامة ❌ حمراء، فغالباً بوتيكات يحجب سيرفرات GitHub. أرسل لي صورة منها.

## الخطوة 4: التشغيل

من نفس المكان اضغط **Run workflow** بدون علامة Test.
بتوصلك رسالة «👋 بدأت المراقبة»، وبعدها يشتغل لحاله كل 5 دقائق تقريباً.

## أسئلة

**أبي يراقب ألوان معينة بس؟**
Settings ثم Secrets and variables ثم Actions ثم تبويب **Variables** ثم **New repository variable**.
الاسم: `WATCH` والقيمة كلمات من اسم اللون مفصولة بفاصلة، مثل: `بابل غم,تشوكليت براون`

**أبي أوقفه؟**
تبويب Actions ثم PUFF restock alert ثم زر **…** ثم **Disable workflow**.

**هل فعلاً كل 5 دقائق بالضبط؟**
5 دقائق هي أقل مدة يسمح فيها GitHub، وفي أوقات الزحمة يتأخر التشغيل (أحياناً 10 أو 20 دقيقة) وأحياناً يتخطى مرة. يعني توقع التنبيه خلال 5 إلى 20 دقيقة من التوفر.

**هل المستودع العام آمن؟**
أي أحد يقدر يشوف الكود، بس التوكن ورقم المحادثة مخفيين في Secrets وما يظهرون لأحد. والمستودع العام مجاني بلا حد للدقائق.

**ملاحظة:** GitHub يوقف الجداول التلقائية إذا ما صار أي تحديث بالمستودع 60 يوم. البرنامج يحفظ تحديث كل ما تغيّر المخزون، فغالباً ما يوقف. لو وقف، تجيك رسالة إيميل من GitHub وتقدر تفعّله بضغطة.

## تشغيل كل 5 دقائق بالضبط (cron-job.org)

جدول GitHub يتأخر، فنخلي موقع cron-job.org المجاني يشغّله كل 5 دقائق:

1. **رمز وصول من GitHub:** افتح https://github.com/settings/personal-access-tokens/new
   - Token name: `cron` ، Expiration: سنة
   - Repository access: **Only select repositories** واختر `puff-alert`
   - Permissions ← Repository permissions ← **Actions: Read and write**
   - Generate token وانسخه
2. **cron-job.org:** سجّل حساب ثم **Create cronjob**
   - URL: `https://api.github.com/repos/shopstore1448-rgb/puff-alert/actions/workflows/puff-alert.yml/dispatches`
   - Execution schedule: Every 5 minutes
   - تبويب Advanced: Request method **POST**
   - Headers:
     - `Authorization` = `Bearer` ثم مسافة ثم الرمز
     - `Accept` = `application/vnd.github+json`
     - `Content-Type` = `application/json`
   - Request body: `{"ref":"main"}`
   - Save، وزر Test run لازم يطلع 204
